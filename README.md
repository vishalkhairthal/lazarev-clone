# Lazarev Clone

A modern animated frontend clone inspired by the award-winning Lazarev agency website.  
Built with a strong focus on smooth animations, modern UI design, interactive scrolling, and immersive user experience.

---

## 🚀 Live Demo

[View Live Project](https://lazarev-clone-delta.vercel.app/)

---

## 📌 Features

- Smooth scroll-based animations
- Modern dark UI design
- Interactive sections
- Responsive layout (working on further optimization)
- GSAP-powered motion effects
- Clean typography and visual hierarchy
- Minimal and immersive landing page experience

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- GSAP (GreenSock Animation Platform)
